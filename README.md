# Raízes do Nordeste

Sistema de delivery para restaurante de culinária nordestina, desenvolvido como projeto acadêmico da disciplina de Projeto Multidisciplinar.

## Sobre o projeto

O sistema simula o fluxo completo de um pedido delivery, desde a escolha da unidade e consulta ao cardápio até o pagamento e acompanhamento do pedido.

A aplicação contempla:

* Cadastro e autenticação de usuários;
* Cardápio por unidade;
* Carrinho de compras;
* Promoções;
* Pagamento simulado com integração externa;
* Acompanhamento do status do pedido;
* Programa de fidelidade;
* Consentimento e informações relacionadas à LGPD;
* Interface responsiva com abordagem mobile-first.

## Tecnologias

* HTML5
* CSS3
* JavaScript (ES6)
* Font Awesome
* Google Fonts
* LocalStorage
